# Simulation Code for *Significance Testing for Causal Mediation Analysis in Single Case Experimental Designs*

This repository contains the R code used to conduct the simulation study for **Significance Testing for Causal Mediation Analysis in Single Case Experimental Designs**. 
The simulation framework consists of two main stages: **1. Data Generating Progress** and **2. Statistical Simulation (Parallel computing framework)**.

The overall workflow is:

```text
SIMU_param_pool.Rdata
        │
        ▼
     1. Data Generating Progress (DGP.R)
        │
        │  DGP function
        ▼
SIMU_dataset.Rdata (DGP dataset for the simulation)
        │
        ▼
     2. Statistical Simulation (main.R)
        │
        │  simulation based on parallel computing framework
        ▼
Regression modeling
        │
        │
        ▼
Mediation effect estimation & CI-based significance testing
        │
        ├── MCDLT_CI.R   (Monte Carlo procedure & Delta procedure)
        ├── RP_test_CI_arima.R   (RP procedure for ARIMA)
        ├── RP_test_CI_dbfit.R   (RP procedure for DBfit)
        ├── RP_test_CI_gls.R     (RP procedure for GLS)
        ├── RP_test_CI_neweywest.R (RP procedure for Newey West)
        ├── RP_test_CI_ols.R     (RP procedure for OLS)
        ├── RP_test_CI_orcutt.R (RP procedure for Cochrane-Orcutt)
        │
        ▼
SIMU_Summary.Rdata (Simulation output)
```

## Repository Structure

| File                     | Description                                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `DGP.R`                  | Generates simulation data (Interrupted Time series) using the data-generator function and the parameter pool stored in `SIMU_param_pool.Rdata`.                   |
| `SIMU_param_pool.Rdata`  | Contains the parameter pool used by the data-generating process.                                                               |
| `SIMU_dataset.Rdata`     | Contains the simulated datasets generated by `DGP.R`.                                                                          |
| `main.R`                 | Main simulation program implementing the parallel computing framework.                                                         |
| `MCDLT_CI.R`             | Running Confidence-interval-based significance testing procedures (Monte Carlo procedure & Delta procedure) for all regression methods |
| `RP_test_CI_arima.R`     | Regression modeling and mediation effects inference using ARIMA regression and RP testing procedures.                                                         |
| `RP_test_CI_dbfit.R`     | Regression modeling and mediation effects inference using DBfit regression and RP testing procedures.                                                        |
| `RP_test_CI_gls.R`       | Regression modeling and mediation effects inference using generalized least squares (GLS) regression and RP testing procedures.                                             |
| `RP_test_CI_neweywest.R` | Regression modeling and mediation effects inference using Newey–West regression and RP testing procedures.                                                  |
| `RP_test_CI_ols.R`       | Regression modeling and mediation effects inference using ordinary least squares (OLS) regression and RP testing procedures.                                                |
| `RP_test_CI_orcutt.R`    | Regression modeling and mediation effects inference using Cochrane–Orcutt regression and RP testing procedures.                                               |
| `SIMU_Summary.Rdata`     | Contains the summarized results from the complete statistical simulation study.                                                            |

## Requirements

The simulation study is implemented in **R** and uses parallel computing to improve computational efficiency.

Before running the simulation, make sure that:

* R is installed on your system.
* All required R packages are installed.
* The files in this repository are placed in the same working directory.
* Sufficient computational resources are available for the parallel simulation.

The required packages can be installed using:

```r
install.packages(c(
  "parallel"
  # Add other required packages here
))
```

## Simulation Workflow

The simulation consists of two main steps.

### Step 1: Data Generation

The script `DGP.R` generates the simulation datasets based on the parameter pool stored in:

```text
SIMU_param_pool.Rdata
```

The `DGP` function defined in `DGP.R` implements the data-generating process.

To generate the simulation datasets, first set the working directory to the repository directory and run:

```r
load("SIMU_param_pool.Rdata")
source("DGP.R")
```

Then execute the `DGP` function according to the parameter settings specified in the script.

The generated datasets are saved as:

```text
SIMU_dataset.Rdata
```

The resulting `SIMU_dataset.Rdata` file serves as the input for the main simulation program.

### Step 2: Parallel Simulation

The script `main.R` is the main simulation program and implements a **parallel computing framework**.

The script first loads the simulated datasets:

```r
load("SIMU_dataset.Rdata")
```

It then calls the corresponding analysis functions to perform regression modeling, mediation effect estimation, and confidence-interval-based significance testing.

The analysis functions are implemented in the following files:

```text
MCDLT_CI.R
RP_test_CI_arima.R
RP_test_CI_dbfit.R
RP_test_CI_gls.R
RP_test_CI_neweywest.R
RP_test_CI_ols.R
RP_test_CI_orcutt.R
```

These functions apply different regression modeling approaches to the simulated data and evaluate mediation effects using confidence-interval-based significance testing.

### Running the Simulation

After generating `SIMU_dataset.Rdata`, run:

```r
source("main.R")
```

The number of parallel workers can be adjusted in `main.R` according to the available computational resources.

> **Note:** The full simulation may require substantial computational time and memory, depending on the number of simulation scenarios, sample sizes, and number of replications.

## Output

The complete simulation results are summarized and stored in:

```text
SIMU_Summary.Rdata
```

This file contains the results generated across the simulation scenarios and analysis methods. It can be loaded into R using:

```r
load("SIMU_Summary.Rdata")
```

The resulting objects can then be used to summarize and compare the performance of the different analytical strategies.

## Reproducibility

To reproduce the simulation study from the beginning, follow these steps:

```text
1. Load SIMU_param_pool.Rdata
2. Run DGP.R
3. Generate SIMU_dataset.Rdata
4. Run main.R
5. Perform parallel simulation
6. Obtain SIMU_Summary.Rdata
```

In short:

```text
Parameter Pool
      ↓
   DGP.R
      ↓
SIMU_dataset.Rdata
      ↓
   main.R
      ↓
Parallel Simulation
      ↓
Regression & Mediation Analysis & significance testing for mediation effects
      ↓
SIMU_Summary.Rdata
```
